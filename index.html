Документация по проекту "Desktop Clock"

Общее описание

Desktop Clock — это легковесный виджет для рабочего стола Windows, который отображает текущее время с помощью иконок обычных папок. Проект представляет собой набор скриптов и ресурсов, объединенных в один установочный `.exe` файл.

Основная идея заключается в том, чтобы каждую минуту обновлять иконки четырех папок на рабочем столе, каждая из которых соответствует одной цифре текущего времени (например, для 12:45 папки примут иконки "1", "2", "4", "5").

Состав проекта

Проект состоит из нескольких ключевых файлов, работающих вместе:

  • info.vbs: Мини-скрипт, который запускается первым. Он показывает информационное окно с описанием программы и кнопками "ОК" / "Отмена", позволяя пользователю подтвердить или прервать установку.
  • Install-Clock.ps1: Основной установочный скрипт, написанный на PowerShell. Он выполняет всю логику установки: создает папки, копирует ресурсы, настраивает пути и создает задачу в Планировщике задач Windows.
  • time.vbs: "Движок" виджета. Этот VBScript запускается каждую минуту Планировщиком задач. Он получает текущее время, определяет нужные иконки для каждой цифры и применяет их к папкам на рабочем столе.
  • Update Folder Icons.xml: Шаблон задачи для Планировщика. `Install-Clock.ps1` использует его для создания задачи, которая будет запускать `time.vbs` ежеминутно.
  • Файлы иконок (*.ico): Набор из 11 иконок (0.ico - 9.ico и o.ico), которые используются для отображения цифр и разделителя.
  • Установщик .exe: Финальный файл, созданный с помощью WinRAR SFX. Он содержит все вышеперечисленные файлы и автоматизирует весь процесс установки.

Процесс установки

Когда пользователь запускает финальный .exe файл, происходит следующее:

  1. Запускается info.vbs, показывая приветственное окно.
  2. Если пользователь нажимает "Отмена", процесс прерывается.
  3. Если пользователь нажимает "ОК", SFX-архив распаковывает все файлы во временную системную папку.
  4. Запускается основной скрипт Install-Clock.ps1 с правами администратора.
  5. Скрипт создает на рабочем столе папки: HH, H, o, MM, M.
  6. В папке %LOCALAPPDATA%\DesktopClock создается папка для хранения ресурсов.
  7. Все иконки и скрипт time.vbs копируются в эту папку.
  8. Install-Clock.ps1 автоматически изменяет пути внутри time.vbs и Update Folder Icons.xml на актуальные.
  9. Настроенная задача импортируется в Планировщик задач Windows.
  10. Кэш иконок рабочего стола обновляется, чтобы изменения вступили в силу.
  11. После успешного завершения скрипта временная папка со всеми файлами автоматически удаляется.

Технические детали и финальный код

info.vbs (Информационный скрипт)

Показывает диалоговое окно для подтверждения установки. Возвращает код выхода 0 (ОК) или 1 (Отмена), который используется SFX-архиватором для принятия решения о продолжении.

' --- Настройки текста ---
Dim title, message
title = "Установка Desktop Clock"
message = "Сейчас будет установлен виджет 'Desktop Clock'." & vbCrLf & vbCrLf
message = message & "Он использует 5 папок на рабочем столе для отображения времени." & vbCrLf & vbCrLf
message = message & "Продолжить установку?"

' --- Отображение окна и обработка выбора ---
Dim userChoice
userChoice = MsgBox(message, vbOKCancel + vbQuestion, title)

' Проверяем, что нажал пользователь
If userChoice = vbOK Then
    ' Если "ОК", выходим с кодом 0 (успех, продолжаем)
    WScript.Quit(0)
Else
    ' Если "Отмена" или закрыл окно, выходим с кодом 1 (отмена)
    WScript.Quit(1)
End If

time.vbs (Скрипт обновления иконок)

Основная логика виджета. Запускается каждую минуту для обновления иконок папок. Должен быть сохранен в кодировке **ANSI (Windows-1251)**.

' Отключаем вывод ошибок на экран, чтобы скрипт работал в фоне без окон
On Error Resume Next

Set objShell = CreateObject("WScript.Shell")
Set fso = CreateObject("Scripting.FileSystemObject")

' Пути к папкам на рабочем столе
Dim desktopPath
desktopPath = objShell.ExpandEnvironmentStrings("%USERPROFILE%\Desktop")

Dim folderHH, folderH, folderMM, folderM
folderHH = desktopPath & "\HH"
folderH  = desktopPath & "\H"
folderMM = desktopPath & "\MM"
folderM  = desktopPath & "\M"

' Путь к иконкам (он будет заменен установочным скриптом)
Dim icon_path
icon_path = "C:\Ico\NumbersFolder" ' Этот путь заменится при установке

' Получаем текущее время с ведущими нулями
Dim currentHour, currentMinute
currentHour   = Right("0" & Hour(Now), 2)
currentMinute = Right("0" & Minute(Now), 2)

' Разделяем на отдельные цифры
Dim h1, h2, m1, m2
h1 = Mid(currentHour, 1, 1)
h2 = Mid(currentHour, 2, 1)
m1 = Mid(currentMinute, 1, 1)
m2 = Mid(currentMinute, 2, 1)

' Функция для смены иконки у папки
Sub ChangeIcon(folderPath, iconName)
    If Not fso.FolderExists(folderPath) Then Exit Sub

    Dim desktopIniPath
    desktopIniPath = folderPath & "\desktop.ini"
    
    ' Снимаем атрибуты с папки, чтобы можно было в ней работать
    fso.GetFolder(folderPath).Attributes = fso.GetFolder(folderPath).Attributes And Not 1 ' Снимаем ReadOnly

    ' Удаляем старый desktop.ini, если он есть
    If fso.FileExists(desktopIniPath) Then
        fso.GetFile(desktopIniPath).Attributes = 0 ' Снимаем все атрибуты с файла
        fso.DeleteFile desktopIniPath, True
    End If

    ' Создаем новый desktop.ini
    Dim desktopIniFile
    Set desktopIniFile = fso.CreateTextFile(desktopIniPath, True)
    desktopIniFile.WriteLine "[.ShellClassInfo]"
    desktopIniFile.WriteLine "IconResource=" & icon_path & "\" & iconName & ".ico,0"
    desktopIniFile.Close

    ' Устанавливаем атрибуты: Скрытый (2) и Системный (4) для файла
    fso.GetFile(desktopIniPath).Attributes = 2 + 4
    
    ' Устанавливаем атрибут Только для чтения (1) для папки, чтобы Windows применила иконку
    fso.GetFolder(folderPath).Attributes = fso.GetFolder(folderPath).Attributes Or 1
End Sub

' Применяем иконки
ChangeIcon folderHH, h1
ChangeIcon folderH,  h2
ChangeIcon folderMM, m1
ChangeIcon folderM,  m2

' Завершаем работу скрипта
WScript.Quit

Install-Clock.ps1 (Скрипт установки)

Полный код установщика на PowerShell. Должен быть сохранен в кодировке **UTF-8 with BOM**.

#requires -Version 5.1
#requires -RunAsAdministrator

function Write-Log {
    param(
        [string]$Message,
        [string]$Level = "INFO"
    )
    $timestamp = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
    Write-Host "[$timestamp] [$Level] $Message"
}

try {
    Write-Log "Начало установки виджета часов..."

    # --- 1. Определение путей и переменных ---
    $scriptRoot = $PSScriptRoot
    $desktopPath = [Environment]::GetFolderPath('Desktop')
    
    $assetDir = Join-Path $env:LOCALAPPDATA "DesktopClock"
    
    $clockFolders = @("HH", "H", "o", "MM", "M")
    
    $sourceVbs = Join-Path $scriptRoot "time.vbs"
    $sourceXml = Join-Path $scriptRoot "Update Folder Icons.xml"
    $iconFiles = Get-ChildItem -Path $scriptRoot -Filter "*.ico"

    if (-not (Test-Path $sourceVbs) -or -not (Test-Path $sourceXml) -or $iconFiles.Count -eq 0) {
        throw "Ошибка: Не все файлы (time.vbs, Update Folder Icons.xml, *.ico) найдены."
    }

    # --- 2. Создание папок и копирование файлов ---
    Write-Log "Создание папки для ресурсов: $assetDir"
    if (-not (Test-Path $assetDir)) {
        New-Item -Path $assetDir -ItemType Directory | Out-Null
    }

    Write-Log "Копирование иконок и VBS-скрипта..."
    Copy-Item -Path $iconFiles.FullName -Destination $assetDir -Force
    Copy-Item -Path $sourceVbs -Destination $assetDir -Force
    $vbsPathInAssets = Join-Path $assetDir "time.vbs"

    # --- 3. Настройка файлов ---
    Write-Log "Настройка VBS-скрипта..."
    $vbsContent = Get-Content -Path $vbsPathInAssets -Raw
    $vbsContent = $vbsContent -replace 'icon_path = ".*"', "icon_path = ""$assetDir"""
    Set-Content -Path $vbsPathInAssets -Value $vbsContent -Force -Encoding Default

    Write-Log "Настройка XML-файла для Планировщика задач..."
    $xmlContent = Get-Content -Path $sourceXml -Raw
    $xmlContent = $xmlContent -replace '<Command>time.vbs</Command>', "<Command>$vbsPathInAssets</Command>"
    $tempXmlPath = Join-Path $env:TEMP "TaskDefinition.xml"
    Set-Content -Path $tempXmlPath -Value $xmlContent -Encoding Unicode -Force

    # --- 4. Создание папок на рабочем столе ---
    Write-Log "Создание папок на рабочем столе..."
    foreach ($folder in $clockFolders) {
        $fullPath = Join-Path $desktopPath $folder
        if (-not (Test-Path $fullPath)) {
            New-Item -Path $fullPath -ItemType Directory | Out-Null
        }
    }
    
    # --- 5. Назначение иконки для папки "o" ---
    Write-Log "Назначение иконки для папки 'o'..."
    $oFolderPath = Join-Path $desktopPath "o"
    $oIconPath = Join-Path $assetDir "o.ico"
    $desktopIniPath = Join-Path $oFolderPath "desktop.ini"
    $iniContent = @"
[.ShellClassInfo]
IconResource=$oIconPath,0
"@
    Set-Content -Path $desktopIniPath -Value $iniContent -Force
    & attrib.exe +H +S "$desktopIniPath"
    & attrib.exe +R "$oFolderPath"
    
    # --- 6. Импорт задачи в Планировщик задач ---
    Write-Log "Импорт задачи 'Update Desktop Clock' в Планировщик..."
    schtasks.exe /Create /TN "Update Desktop Clock" /XML "$tempXmlPath" /F
    if ($LASTEXITCODE -ne 0) {
        throw "Не удалось импортировать задачу в Планировщик."
    }
    
    # --- 7. Обновление рабочего стола и очистка ---
    Write-Log "Обновление кэша иконок оболочки..."
    $csharpCode = @"
    using System;
    using System.Runtime.InteropServices;
    public class ShellRefresher {
        [DllImport("shell32.dll", CharSet = CharSet.Ansi, SetLastError = true)]
        public static extern void SHChangeNotify(long wEventId, long uFlags, IntPtr dwItem1, IntPtr dwItem2);
    }
"@
    Add-Type -TypeDefinition $csharpCode
    [ShellRefresher]::SHChangeNotify(0x08000000, 0x0000, [System.IntPtr]::Zero, [System.IntPtr]::Zero)
    
    Write-Log "Очистка временных файлов..."
    Remove-Item -Path $tempXmlPath -Force
    Write-Log "Установка успешно завершена!" -Level "SUCCESS"
}
catch {
    Write-Log "Произошла критическая ошибка:" -Level "ERROR"
    Write-Log $_.Exception.Message -Level "ERROR"
    Read-Host "Нажмите Enter, чтобы выйти."
    exit 1
}
